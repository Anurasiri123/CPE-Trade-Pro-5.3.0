    Trading Guide & Safety Rules
    
      
    
      
    
        
    1. 🧪 Test in DEMO Mode First
    
        
    Run Auto Trading or Manual Trading in DEMO mode for 2–3 days. Observe win rate, strategy execution, and profit results risk-free before switching to LIVE.
    

        
    2. 🛡️ Risk Management & Multi-Platform
    
        
    Spot: Set min quote $11–$20.
    
        Futures: Keep leverage low at 3x–5x to avoid liquidation risk. Set Max Orders to 2–3.
    
        Supported Platforms: Binance, Bybit, OKX, KuCoin, Bitget, Gate.io, MEXC, Kraken, Coinbase, OANDA Forex.
    

        
    3. 🔒 All Platforms API Key Security
    
        
    When creating API Keys on any exchange (Binance, Bybit, OKX, KuCoin, Bitget, Gate.io, MEXC, Kraken, Coinbase, or OANDA Forex): Enable Reading and Spot / Futures / Forex Trading permissions. NEVER enable Withdrawals. Your funds remain 100% secure in your account.
    

        
    4. 📊 Auto Trading Strategy
    
        
    Trades enter only when multiple indicators confirm: Bollinger Bands Lower touch + RSI Oversold + Golden Cross / MACD confirmation with auto TP1, TP2, and Trailing Stop Loss.
